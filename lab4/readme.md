# NPM Project
  
  1 . create project folder 
  2.  right lick on project folder and select open integrated terminal

  3 . type in terminal `npm init -y` press enter 
  4 open package.json file from project folder
  5 . update type as `type:module` in package .json
      ![alt text]()

  6  type in terminal `npm i nodemon -D` to install nodemon , which restarts server while file changes
     -D flag indicate install as dev dependency 
     7 . it creates node_moduls folder and package-lock .json    
     8 . update .gitignore and write projrct-folder /node_modules
